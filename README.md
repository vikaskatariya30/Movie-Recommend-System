# 🎬 Movie Recommend System

A content-based movie recommendation web app built with **Streamlit**. Pick a movie from the dropdown and get 5 similar movie recommendations, complete with posters fetched live from **The Movie Database (TMDb) API**.

## How It Works

The app uses a precomputed **cosine similarity matrix** over movie feature vectors (generated in `model_training.ipynb`) to find the most similar movies to the one you select. Posters for the recommended movies are fetched at runtime from the TMDb API, with automatic retries for transient network/API errors.

## Features

- 🔍 Select any movie from a searchable dropdown
- 🎯 Get 5 similar movie recommendations instantly
- 🖼️ Movie posters fetched dynamically from TMDb
- 🔁 Built-in request retry logic for reliable poster fetching
- 🧠 Recommendation model trained and serialized ahead of time (via pickle) for fast inference

## Tech Stack

- **Python**
- **Streamlit** – web app UI
- **Pandas** – data handling
- **Pickle** – loading the pretrained similarity model
- **Requests** – TMDb API calls with retry/backoff via `urllib3`
- **Jupyter Notebook** (`model_training.ipynb`) – data preprocessing & model (similarity matrix) generation

## Project Structure

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vikaskatariya30/Movie-Recommend-System.git
cd Movie-Recommend-System
```

### 2. Create a virtual environment

```bash
conda create -p .venv python==3.12 -y
conda activate ./.venv
```

### 3. Install dependencies

```bash
pip install -r requirnment.txt
```

### 4. Generate the model files

Run all cells in `model_training.ipynb` to produce `movies_dict.pkl` and `similarity.pkl` in the project root.

### 5. Run the app

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`.
